<Section type="about">
`rencal.calibration.wind.wind_calibrator` defines the concrete wind calibration workflow for converting ERA5 wind resource data and historical generation into fitted wind power curves and long-term load-factor streams.

[`WindCalibrator`](/reference/RenCal/Calibration/rencalcalibrationwindwind_calibrator/#windcalibrator) extends [`Calibrator`](/reference/RenCal/Calibration/rencalcalibrationcalibrator/) for wind technologies, fits Weibull and logistic curve parameters per plant, and writes tabular calibration outputs plus stream artifacts for downstream simulation.

#### Example

```python
from pathlib import Path

from rencal.calibration.wind.wind_calibrator import WindCalibrator

calibrator = WindCalibrator(
    data_path="data",
    plant_id_col="plant_id",
    output_path=Path("outputs"),
    visual_output=False,
    stream_npy_output=True,
)
calibrator.calibrate()
```
</Section>

### WindCalibrator.logistic_function

<Segment>
<Section type="signature">
```python
logistic_function(
    x: int | float | np.ndarray,
    b: float,
    c: float,
    g: float,
) -> float | np.ndarray
```
</Section>

Defines a generalised logistic function in the log domain for stability and calculates its value for any numeric input `x`.

For deeper conceptual context, see [Logistic Power Curve](/concepts/RenCal/calibration/logistic_power_curve/).

The generalized logistic function has five shape parameters; this implementation constrains minimum/maximum to 0 and 1 respectively because load factors are bounded to `[0, 1]`.

The non-log-domain form is:

$$
f(x) = d + \frac{a - d}{\left(1 + \left(\frac{x}{c}\right)^b\right)^g}
$$

where `b` is steepness, `c` is inflection location, and `g` is asymmetry.

<Section type="parameters">
#### Parameters

- <p><code class="key">x</code> <code class="primitive">int</code> | <code class="primitive">float</code> | <code class="primitive">np.ndarray</code></p>
  Input variable(s), i. e.: wind speed.

- <p><code class="key">b</code> <code class="primitive">float</code></p>
  Steepness parameter of the generalised logistic function.

- <p><code class="key">c</code> <code class="primitive">float</code></p>
  X-axis inflection point location parameter of the generalised logistic function.

- <p><code class="key">g</code> <code class="primitive">float</code></p>
  Asymmetry parameter of the generalised logistic function.
</Section>

<InlineSection>
**Returns** <code class="primitive">float</code> | <code class="primitive">np.ndarray</code>
</InlineSection>
</Segment>

### WindCalibrator.weibull_function

<Segment>
<Section type="signature">
```python
weibull_function(
    x: int | float | np.ndarray,
    k_val: float,
    lambda_val: float,
) -> float | np.ndarray
```
</Section>

Calculates the value of a specified Weibull distribution for any numeric input `x`.

For deeper conceptual context, see [Weibull Wind-Speed Distribution](/concepts/RenCal/calibration/weibull_wind_speed_distribution/).

The Weibull density is:

$$
f(x) = \frac{k}{\lambda} \left(\frac{x}{\lambda}\right)^{k - 1} \left(e^{-\left(\frac{x}{\lambda}\right)^k}\right)
$$

where `k` is shape and `λ` is scale.

<Section type="parameters">
#### Parameters

- <p><code class="key">x</code> <code class="primitive">int</code> | <code class="primitive">float</code> | <code class="primitive">np.ndarray</code></p>
  Input variable(s), i. e.: wind speed.

- <p><code class="key">k_val</code> <code class="primitive">float</code></p>
  Shape parameter of the Weibull distribution.

- <p><code class="key">lambda_val</code> <code class="primitive">float</code></p>
  Scale parameter of the Weibull distribution.
</Section>

<InlineSection>
**Returns** <code class="primitive">float</code> | <code class="primitive">np.ndarray</code>
</InlineSection>
</Segment>
