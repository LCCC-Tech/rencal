<Section type="about">
`rencal.core.bucketed_data` contains shared histogram, resampling, and horizon-alignment utilities used by bucket-based simulators such as `WeatherData`.

The module exposes:

- `BucketedData`: utility base class with histogram and distribution optimization helpers.
- `VersionedColumnsNDArray`: array wrapper that tracks canonical columns and transformed versions produced during resampling.

#### Example

```python
# Returned from WeatherData.random_sample(...)
sample = weather_data.random_sample(start, end)

# Access canonical column
base_stream = sample.access_col(1)

# Access first transformed variant of canonical column 1
variant_stream = sample.access_col(1, 1)
```
</Section>
