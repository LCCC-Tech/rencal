<Section type="about">
`rencal.core.bucketer` provides the base class for calendar-aware bucket sampling of historical draw periods.

[`Bucketer`](/reference/RenCal/Core/rencalcorebucketer/#bucketer) partitions the year into custom date buckets (defined by ordered [`ShortDate`](/reference/RenCal/Core/rencalcoreshort_date/#shortdate) boundaries), optionally separates dates into categories, and precomputes lookup tables used by [`random_sample()`](/reference/RenCal/Core/rencalcorebucketer/#bucketerrandom_sample) to draw consecutive historical periods.

#### Example

```python
import datetime as dt
import random

from rencal.simulation.intermittent_bucketer import IntermittentBucketer

bucketer = IntermittentBucketer(
    historical_start_date=dt.datetime(1990, 1, 1),
    historical_end_date=dt.datetime(2025, 12, 31),
    draw_period=7,
)

sample_starts = bucketer.random_sample(
    future_start_date=dt.datetime(2027, 1, 1),
    future_end_date=dt.datetime(2027, 2, 1),
    rng_python=random.Random(22),
)
```
</Section>

## Constructor

### Bucketer

<Segment>
<Section type="signature">
```python
class Bucketer(
    historical_start_date: datetime.datetime,
    historical_end_date: datetime.datetime,
    categories: int,
    draw_period: int,
    bucket_definition: list[ShortDate],
): Bucketer
```
</Section>

Builds bucket/category lookup structures used by sampling operations.

<Section type="parameters">
#### Parameters

- <p><code class="key">historical_start_date</code> <code class="primitive">datetime.datetime</code></p>
  Midnight timestamp for the first historical day available for sampling.

- <p><code class="key">historical_end_date</code> <code class="primitive">datetime.datetime</code></p>
  Midnight timestamp for the last historical day available for sampling.

- <p><code class="key">categories</code> <code class="primitive">int</code></p>
  Number of category partitions used by subclass-specific filtering logic.

- <p><code class="key">draw_period</code> <code class="primitive">int</code></p>
  Number of consecutive days represented by one sampled draw.

- <p><code class="key">bucket_definition</code> <code class="primitive">list[ShortDate]</code></p>
  Strictly increasing list of bucket boundaries that partitions the year.
</Section>

<InlineSection>
**Returns** [<code class="type">Bucketer</code>](#Bucketer)
</InlineSection>

<InlineSection>
**Raises**
- <code class="type">TypeError</code>: If bucket definition is not a list.
- <code class="type">ValueError</code>: If date ordering or bucket constraints are invalid.
</InlineSection>
</Segment>
