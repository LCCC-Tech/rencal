<Section type="about">
`rencal.calibration.calibrator` defines the abstract base class for intermittent generator calibration workflows.

`Calibrator` is responsible for loading the plant, generation, and ERA5 resource datasets needed by a concrete calibrator implementation, then exposing the required workflow steps as abstract methods.

Because this class inherits from `ABC`, instantiate a concrete subclass such as `WindCalibrator` rather than `Calibrator` directly.

#### Example

```python
from rencal.calibration.wind.wind_calibrator import WindCalibrator

calibrator = WindCalibrator(
    data_path="data",
    plant_id_col="plant_id",
    output_path="outputs",
)
calibrator.calibrate()
```
</Section>

## Constructor

### Calibrator

<Segment>
<Section type="signature">
```python
class Calibrator(
    data_path: str = None,
    plant_id_col: str = None,
    loader: DataLoader | None = None,
): Calibrator
```
</Section>

Initialise a calibrator instance.

The `Calibrator` is an abstract class that specifies the methods any intermittent generator's calibration should include, as well as setting up and loading input datasets from the configuration file or user-specified paths.

<Section type="parameters">
#### Parameters

- <p><code class="key">data_path</code> <code class="primitive">str</code></p>
  Path to the directory containing the input data files.

- <p><code class="key">plant_id_col</code> <code class="primitive">str</code></p>
  Name of the ID column designating a power plant in the input.

- <p><code class="key">loader</code> <code class="primitive">DataLoader | None</code></p>
  Optional pre-configured data loader. When supplied it is used as-is (overriding `data_path`), allowing inputs to be read from non-default locations or sources (e.g. a cloud loader reading directly from Blob storage) instead of the default `LocalDataLoader` layout.
</Section>
