<Section type="about">
This class simulates coal prices using a combination of Geometric Brownian Motion and Ornstein-Uhlenbeck processes. The dual stochastic process approach captures both the trending behavior and mean-reverting characteristics of coal prices.

#### Simple Example

Here's a basic example of simulating coal prices:

```python
from quantlib.commodities.CommodityPriceSimulation import CoalPrice
from quantlib.database.DatabaseDelta import DatabaseDelta
import datetime as dt
import numpy as np

# Create database connection
connection = DatabaseDelta()

# Create coal price simulation
coal_sim = CoalPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2024, 12, 31),
    number_of_simulations=100,
    connection=connection,
    numpy_rng=np.random.default_rng(42)
)

# Run simulation to get daily fuel prices
daily_prices = coal_sim.run()
```

#### Advanced Example with Price Analysis

This example shows how to analyze the simulated coal prices:

```python
# Create coal price simulation with more paths
coal_sim = CoalPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2025, 12, 31),
    number_of_simulations=1000,
    connection=connection
)

# Run simulation
daily_prices = coal_sim.run()  # Returns prices in £/MWh

# Access the raw simulated prices ($/tonne)
raw_prices = coal_sim.Pt

# Plot both raw and converted prices
coal_sim.plot_Simulated_Curve(raw_price=True, paths=50)  # Raw $/tonne
coal_sim.plot_Simulated_Curve(raw_price=False, paths=50) # Converted £/MWh

# The conversion includes:
# - USD to GBP exchange rate
# - Transport costs
# - Calorific value conversion
```

The coal price simulation combines GBM for long-term trends with an Ornstein-Uhlenbeck process for short-term mean reversion, providing realistic price dynamics.

## Methods

### run

<Segment>
<Section type="signature">
```ts
run(): ndarray
```
</Section>

Defines one simulation of the coal price. The Pt attribute is updated as a NumPy array of simulated prices and daily fuel prices are returned transforming the Pt array.

The simulation combines:
- Geometric Brownian Motion (GBM) for the base price evolution
- Ornstein-Uhlenbeck (OU) process for mean-reverting adjustments

<InlineSection>
**Returns** Daily fuel prices (£/MWh) for coal.
</InlineSection>

<InlineSection>
**Return type** <code class="primitive">np.ndarray</code>
</InlineSection>
</Segment>

### daily_Fuel_Price

<Segment>
<Section type="signature">
```ts
daily_Fuel_Price(prices: ndarray): ndarray
```
</Section>

Calculates the daily fuel price (£/MWh) for coal. This method converts raw coal prices ($/tonne) to fuel prices (£/MWh) by:
1. Converting USD to GBP using exchange rates
2. Adding transport costs
3. Converting using calorific value

<Section type="parameters">
#### Parameters

- <p><code class="key">prices</code> <code class="primitive">np.ndarray</code></p>
  The raw coal prices in $/tonne.
</Section>

<InlineSection>
**Returns** The daily fuel price in £/MWh.
</InlineSection>

<InlineSection>
**Return type** <code class="primitive">np.ndarray</code>
</InlineSection>
