<Section type="about">
This class implements the Ornstein-Uhlenbeck process, a mean-reverting stochastic process. It is commonly used to model interest rates, currency exchange rates, and commodity prices.

#### Simple Example

Here's a simple example of creating an Ornstein-Uhlenbeck process:

```python
from quantlib.commodities.Stochastic import OrnsteinUhlenbeck
import numpy as np

# Create an Ornstein-Uhlenbeck process
ou = OrnsteinUhlenbeck(
    n=365,
    sigma=0.2,
    theta=100.0,
    kappa=0.5,
    paths=100,
    numpy_rng=np.random.default_rng(42)
)

# Generate paths
paths = ou.run_Path()
```

#### Advanced Example with Maximum Likelihood Estimation

Here's a more advanced example showing how to calibrate the Ornstein-Uhlenbeck process using historical data:

```python
from quantlib.commodities.Stochastic import OrnsteinUhlenbeck, max_Likelihood_Estimation
import numpy as np

# Historical price data
historical_prices = np.array([100, 102, 98, 101, 99, 103, 97, 100, 102, 99])

# Calibrate parameters using Maximum Likelihood Estimation
optimal_sigma, optimal_kappa = max_Likelihood_Estimation(historical_prices)

# Create calibrated process
ou = OrnsteinUhlenbeck(
    n=252,  # Trading days
    sigma=optimal_sigma,
    theta=np.mean(historical_prices),  # Use mean as long-term level
    kappa=optimal_kappa,
    paths=1000,
    numpy_rng=np.random.default_rng(42)
)

# Generate future paths
future_paths = ou.run_Path()
```

The Ornstein-Uhlenbeck process is particularly useful for modeling mean-reverting phenomena in commodity markets.
