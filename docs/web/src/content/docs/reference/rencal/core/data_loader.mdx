### LocalDataLoader

<Segment>

```python
class LocalDataLoader(data_path: str = DOWNLOAD_DATA_DIR)
```

Filesystem-backed implementation of `DataLoader`.

#### Constructor Parameters
- `data_path (str)`: Base data directory.

#### Methods

##### load_plant_data

```python
load_plant_data(id_column: str = PLANT_ID_COLUMN) -> PlantDatasetModel
```

Loads plant data from local file and renames source ID column into internal `plant_id` field.

**Parameters**
- `id_column (str)`: Source column name containing plant IDs.

**Returns**
- `PlantDatasetModel`

**Raises**
- `FileNotFoundError`: If plant data file is missing.

##### load_generation_data

```python
load_generation_data(id_column: str = PLANT_ID_COLUMN) -> GenerationDatasetModel
```

Loads generation parquet data and normalizes source ID column into internal `plant_id` field.

**Parameters**
- `id_column (str)`: Source column name containing plant IDs.

**Returns**
- `GenerationDatasetModel`

**Raises**
- `FileNotFoundError`: If generation data file is missing.

##### load_era5_data

```python
load_era5_data() -> ERA5DatasetModel
```

Discovers and loads local ERA5 NetCDF files, resolves time dimension naming, concatenates and sorts on time, casts float64 data variables to float32, and filters to standard wind/solar variables.

**Returns**
- `ERA5DatasetModel`

**Raises**
- `FileNotFoundError`: If no ERA5 NetCDF files are found.
- `ValueError`: If files cannot be loaded, time dimension is invalid, concatenation fails, or no standard ERA5 variables are present.

##### path_resolver_weather_data

```python
path_resolver_weather_data(basename: str) -> str | Path
```

Resolves calibrated weather artifact basename into calibrated directory path.

**Parameters**
- `basename (str)`: Artifact file name.

**Returns**
- `str | Path`

##### check_historical_weather

```python
check_historical_weather() -> dict[str, Any]
```

Validates calibrated wind historical NPY against its manifest and returns manifest metadata enriched with `basename`.

**Returns**
- `dict[str, Any]`: Manifest metadata used by simulation metadata builders.

**Raises**
- `FileNotFoundError`: If calibrated wind NPY file is missing.
- `ValueError`: If manifest consistency checks fail.

##### get_prefix_histograms

```python
get_prefix_histograms() -> NDArray | None
```

Loads calibrated prefix histogram artifact as read-only memmap.

**Returns**
- `NDArray | None`: Loaded histogram matrix or `None` if unavailable/unreadable.

##### get_historical_weather

```python
get_historical_weather() -> NDArray | None
```

Loads calibrated historical NPY artifact as read-only memmap.

**Returns**
- `NDArray | None`: Historical data array or `None` if unavailable/unreadable.

##### verify_npy_against_manifest (static)

```python
verify_npy_against_manifest(
    npy_path: str | Path,
    manifest_path: str | Path,
) -> dict[str, Any]
```

Validates NPY integrity against manifest by checking SHA-256 hash, column count sanity, and file size.

**Parameters**
- `npy_path (str | Path)`: Path to NPY artifact.
- `manifest_path (str | Path)`: Path to JSON manifest.

**Returns**
- `dict[str, Any]`: Parsed manifest.

**Raises**
- `ValueError`: If checksum, schema sanity, or size checks fail.
