<Section type="about">
This class generates smoothed forward curves for commodity prices. It extracts market data and applies various smoothing techniques including the SOFM (Self-Organizing Feature Map) method and polynomial curve fitting to create daily price curves from monthly contract data.

#### Simple Example

Here's how to create a forward curve:

```python
from quantlib.commodities.SmoothedForwardCurve import ForwardCurve
from quantlib.database.DatabaseDelta import DatabaseDelta
import datetime as dt

# Create database connection
connection = DatabaseDelta()

# Create forward curve for gas
gas_curve = ForwardCurve(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2024, 12, 31),
    commodity="Gas",
    connection=connection
)

# Build the smoothed forward curve
dates, prices = gas_curve.build_Forward_Curve()
```

#### Advanced Example with Different Smoothing Methods

This example shows the different smoothing approaches:

```python
# Create forward curve
coal_curve = ForwardCurve(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2025, 12, 31),
    commodity="Coal",
    connection=connection
)

# Different smoothing methods available:

# 1. SOFM Method - Advanced self-organizing smoothing
dates1, prices1 = coal_curve.forward_Curve_Smoothing_SOFM_Method()

# 2. Polynomial smoothing
dates2, prices2 = coal_curve.forward_Curve_Smoothing_Polynomial()

# 3. SOFM + Polynomial combination
dates3, prices3 = coal_curve.forward_Curve_Smoothing_SOFM_And_Polynomial()

# 4. No smoothing - just forward fill
dates4, prices4 = coal_curve.forward_Curve_No_Smoothing()

# Plot results to compare
coal_curve.plot_Results()

# The forward curve handles:
# - Monthly, quarterly, seasonal, and yearly contracts
# - Missing data interpolation
# - Price smoothing between contract periods
# - Carbon-specific simplified curves
```

Forward curves are essential for commodity price simulation and risk management.

## Methods

### build_Forward_Curve

<Segment>
<Section type="signature">
```ts
build_Forward_Curve(): tuple
```
</Section>

The main method called in CommodityPriceSimulation to generate forward curves. Returns different formats based on commodity type:
- Power: Returns contract dates and prices (no smoothing)
- Gas/Carbon/Coal: Returns daily smoothed curves

<InlineSection>
**Returns** A tuple containing:
- For Power: (contract_list, price_list)
- For others: (daily_dataframe, daily_price_list)
</InlineSection>

<InlineSection>
**Return type** <code class="primitive">tuple</code>
</InlineSection>
</Segment>
