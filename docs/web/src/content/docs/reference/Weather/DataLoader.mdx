<Section type="about">
The data loader module defines a common loader interface and a local filesystem implementation for reading plant metadata, generation time series, and ERA5 weather data.

`LocalDataLoader` expects a base directory containing the following subdirectories:

- `plant/` for plant metadata files
- `generation/` for generation time-series files
- `era5/` for ERA5 NetCDF files (`*.nc`)

If expected files are missing, user-facing methods raise `FileNotFoundError` with the missing path.

#### Example

```python
from weather.core.data_loader import LocalDataLoader

loader = LocalDataLoader(data_path="data")
plant = loader.load_plant_data()
generation = loader.load_generation_data()
era5 = loader.load_era5_data()
```
</Section>

### LocalDataLoader.load_era5_data

<Segment>
<Section type="signature">
```python
load_era5_data() -> ERA5DatasetModel
```
</Section>

Loads ERA5 weather data from all `.nc` files discovered in `era5/`.

Behavior relevant to users:
- Auto-discovers all NetCDF files in `era5/`.
- Normalizes the temporal dimension to `time` (accepts source dimensions `time` or `valid_time`).
- Filters variables to the standard configured ERA5 wind and solar variable set.
- Casts data variables from `float64` to `float32` when applicable.
- Concatenates multiple files along `time` and sorts chronologically.
- Skips unreadable individual files; fails if none can be loaded successfully.

<InlineSection>
**Returns** <code class="type">ERA5DatasetModel</code>
</InlineSection>

<Section type="parameters">
#### Raises

- <p><code class="type">FileNotFoundError</code></p>
  If no `.nc` files are found in `era5/`.

- <p><code class="type">ValueError</code></p>
  If no files can be loaded successfully, if files do not contain a valid time dimension (`time` or `valid_time`), if concatenation fails, or if no standard ERA5 variables are found.
</Section>

#### Example

```python
from weather.core.data_loader import LocalDataLoader

loader = LocalDataLoader(data_path="data")
era5 = loader.load_era5_data()
# era5.data is an xarray.Dataset filtered to standard ERA5 variables
```
