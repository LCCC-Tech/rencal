<Section type="about">
`rencal.calibration.calibrator` defines the abstract calibration interface used by intermittent technology-specific calibrators.

[`Calibrator`](/reference/rencal/calibration/rencalcalibrationcalibrator/#calibrator) is responsible for loading plant, generation, and ERA5 resource datasets required by a concrete calibrator implementation, then exposing the required workflow steps as abstract methods.

Because this class inherits from `ABC`, instantiate a concrete subclass such as [`WindCalibrator`](/reference/rencal/calibration/rencalcalibrationwindwind_calibrator/#windcalibrator) rather than [`Calibrator`](/reference/rencal/calibration/rencalcalibrationcalibrator/#calibrator) directly.

#### Example

```python
from rencal.calibration.wind.wind_calibrator import WindCalibrator

calibrator = WindCalibrator(
    data_path="data",
    plant_id_col="plant_id",
    output_path="outputs",
)
calibrator.calibrate()
```
</Section>
