<Section type="about">
The `weather_data` module encapsulates the logic needed to generate future hourly loadfactor samples for intermittent generators (wind and solar). It builds on the `BucketedData` base class, uses an `IntermittentBucketer` to preserve calendar patterns, and supports inverse-CDF resampling to meet user-defined target averages.

`WeatherData` uses a JSON-parsed `HistoricalMetadata` descriptor plus a process-scope cache keyed by the historical NPY basename to enable safe, lazy loading in distributed workloads. It supports two sampling modes via the `ignore_zeros` flag:

- **ignore_zeros = False (wind):** all loadfactor values participate in histogram building and resampling.
- **ignore_zeros = True (solar):** zero-valued hours (nighttime) are preserved; histograms and inverse-CDF resampling operate only on non-zero values. Desired averages are automatically rescaled to daytime-only averages.

#### Example Usage

```python
import datetime as dt
import numpy as np

from rencal.simulation.rencal_data import HistoricalMetadata, WeatherData

# Example metadata, usually parsed from JSON
metadata = HistoricalMetadata(
    npy_basename="historic_wind.npy",
    path_resolver=lambda basename: f"/mnt/data/{basename}",
    data_limit_left=dt.datetime(1980, 1, 1),
    data_limit_right=dt.datetime(2026, 1, 1),
    columns=["wind_lf"],
    hours_per_block=24,
)

weather_data = WeatherData(
    metadata=metadata,
    historical_start_date=dt.datetime(1990, 1, 1),
    historical_end_date=dt.datetime(2025, 12, 31),
    desired_averages={0: [0.38]},
    prefix_histograms=None,
    historical_data=None,
    ignore_zeros=False,
)

sample = weather_data.random_sample(
    future_start_date=dt.datetime(2027, 1, 1),
    future_end_date=dt.datetime(2027, 1, 31),
)
```

<Section type="parameters">
#### Parameters

- <p><code class="key">npy_basename</code> <code class="primitive">str</code></p>

  Callable that maps the NPY basename to a filesystem path on the executing host.

- <p><code class="key">data_limit_left</code> <code class="primitive">datetime.datetime</code> | <code class="primitive">pandas.Timestamp</code></p>
  Earliest datetime represented in the historical NPY file.

- <p><code class="key">data_limit_right</code> <code class="primitive">datetime.datetime</code> | <code class="primitive">pandas.Timestamp</code></p>
  Latest datetime represented in the historical NPY file.

- <p><code class="key">columns</code> <code class="primitive">Sequence[str]</code></p>
  Column names/identifiers in the NPY file.

- <p><code class="key">hours_per_block</code> <code class="primitive">int</code> | <code class="primitive">None</code></p>
  Block size used when building prefix histograms (optional; required for fast histogram queries).

### WeatherData

<Segment>
<Section type="signature">
```python
class WeatherData(
    metadata: HistoricalMetadata,
    historical_start_date: DateTimeLike = datetime.datetime(1980, 1, 1),
    historical_end_date: DateTimeLike = datetime.datetime(2026, 1, 1),
    desired_averages: dict[int, list[float]] = {},
    prefix_histograms: NDArray[np.uint32] | None = None,
    historical_data: NDArray[np.floating] | None = None,
    ignore_zeros: bool = False,
): WeatherData
```
</Section>

<Section type="parameters">
#### Parameters

- <p><code class="key">metadata</code> [<code class="type">HistoricalMetadata</code>](#HistoricalMetadata)</p>
  JSON-backed descriptor (basename, path resolver, time limits, columns).

- <p><code class="key">historical_start_date</code> <code class="primitive">datetime.datetime</code> | <code class="primitive">pandas.Timestamp</code></p>
  Earliest date to consider for bucketed sampling.

- <p><code class="key">historical_end_date</code> <code class="primitive">datetime.datetime</code> | <code class="primitive">pandas.Timestamp</code></p>
  Latest date to consider for bucketed sampling.

- <p><code class="key">desired_averages</code> <code class="primitive">dict[int, list[float]]</code></p>
  Mapping of column index to target average(s). Multiple averages per column produce multiple output columns.

- <p><code class="key">prefix_histograms</code> <code class="primitive">NDArray[np.uint32]</code> | <code class="primitive">None</code></p>
  Pre-computed prefix histograms for fast histogram queries.

- <p><code class="key">historical_data</code> <code class="primitive">NDArray[np.floating]</code> | <code class="primitive">None</code></p>
  Raw historical data array. Required when `desired_averages` is non-empty and no prefix histograms are provided, or when `ignore_zeros` is True for zero-count adjustment.

- <p><code class="key">ignore_zeros</code> <code class="primitive">bool</code></p>
  If True, zero-valued loadfactors are excluded from histogram building and inverse-CDF resampling (solar mode).
</Section>

**Returns** [<code class="type">WeatherData</code>](#WeatherData)

### random_sample

<Segment>
<Section type="signature">
```python
random_sample(
    future_start_date,
    future_end_date,
    python_rng=random.Random(40),
    numpy_rng=np.random.default_rng(22),
) -> NDArray[np.floating]
```
</Section>

Generates a random sample of future weather loadfactors by stitching historical periods and optionally applying inverse-CDF resampling to hit target averages.

<Section type="parameters">
#### Parameters

- <p><code class="key">future_start_date</code> <code class="primitive">datetime.datetime</code> | <code class="primitive">pandas.Timestamp</code></p>
  Earliest datetime to include in the sample (inclusive from 00:00).

- <p><code class="key">future_end_date</code> <code class="primitive">datetime.datetime</code> | <code class="primitive">pandas.Timestamp</code></p>
  Latest date to include in the sample (inclusive until 23:00).

- <p><code class="key">python_rng</code> <code class="primitive">random.Random</code></p>
  Python RNG instance for reproducible sampling of historical periods.

- <p><code class="key">numpy_rng</code> <code class="primitive">numpy.random.Generator</code></p>
  NumPy RNG instance for reproducible inverse-CDF sampling.
</Section>

<InlineSection>
**Returns** An array of shape (n_hours_in_horizon, n_output_columns) containing the generated sample.
</InlineSection>
</Segment>
