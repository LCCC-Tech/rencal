## Functions

### main
<Segment>

```python
main() -> None
```

Runs full download flow and logs loaded plant, generation, and ERA5 datasets.

This function is intended as a simple operational/demo entrypoint rather than a reusable library API.

**Returns**
- `None`
</Segment>

### run_data_loop
<Segment>

```python
run_data_loop() -> None
```

Builds `HistoricalMetadata` and `WeatherData`, then prints a sampled transformed stream column.

The routine demonstrates manifest validation, prefix-histogram usage, and average-adjusted weather sampling.

**Returns**
- `None`
