## Class

### ShortDate

<Segment>

```python
class ShortDate(date)
```

Stores month/day and implements leap-safe comparisons and context-based arithmetic.

#### Constructors

##### ShortDate

```python
ShortDate(date)
```

Constructs from object exposing `month` and `day` attributes.


- `ShortDate`


#### Methods

##### to_datetime


##### add_with_context


##### subtract_with_context


**Returns**

##### __sub__

```python
__sub__(timedelta | ShortDate)
```

Subtracting `datetime.timedelta` returns shifted `ShortDate`; subtracting `ShortDate` returns day distance.

**Returns**
- `ShortDate | int`

#### Properties

##### month

`int` month value (1-12).

**Raises**
- `TypeError`: If assigned month is not integer.
- `ValueError`: If month outside `[1, 12]`.

##### day

`int` day value valid for month under non-leap-year constraints.

**Raises**
- `TypeError`: If assigned day is not integer.
- `ValueError`: If invalid day for month.
