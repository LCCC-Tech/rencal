<Section type="about">
`rencal.calibration.solar.solar_calibrator` defines the concrete solar calibration workflow for converting ERA5 solar resource data and historical generation into fitted PV curves and long-term load-factor streams.

[`SolarCalibrator`](/reference/rencal/calibration/rencalcalibrationsolarsolar_calibrator/#solarcalibrator) extends [`Calibrator`](/reference/rencal/calibration/rencalcalibrationcalibrator/) for solar technologies, estimates plant-specific `gamma` and `NOCT` parameters, and writes tabular calibration outputs plus stream artifacts for downstream simulation.

#### Example

```python
from pathlib import Path

from rencal.calibration.solar.solar_calibrator import SolarCalibrator

calibrator = SolarCalibrator(
    data_path="data",
    plant_id_col="plant_id",
    output_path=Path("outputs"),
    visual_output=False,
    stream_npy_output=True,
)
calibrator.calibrate()
```
</Section>

### SolarCalibrator.solar_regression_model

<Segment>
<Section type="signature">
```python
solar_regression_model(
    x_data,
    gamma,
    noct,
) -> np.ndarray
```
</Section>

Defines the NOCT-style solar regression used to map irradiance and temperature to expected plant output.

The model is:

```python
T_cell = T + (NOCT - 20) * G / 800
return (1 - gamma * (T_cell - 25)) * G / 1000
```

where `G` is irradiance and `T` is temperature. This gives a physically plausible PV response that decreases with elevated cell temperature while scaling with available irradiance.

<InlineSection>
**Returns** <code class="primitive">np.ndarray</code>
</InlineSection>
