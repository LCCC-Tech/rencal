<Section type="about">
This class simulates carbon prices using a Geometric Brownian Motion process applied to forward curves. It includes carbon price support mechanisms and calculates carbon prices per MWh for different fuel types.

#### Simple Example

Here's a basic example of simulating carbon prices:

```python
from quantlib.commodities.CommodityPriceSimulation import CarbonPrice
from quantlib.database.DatabaseDelta import DatabaseDelta
import datetime as dt
import numpy as np

# Create database connection
connection = DatabaseDelta()

# Create carbon price simulation
carbon_sim = CarbonPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2024, 12, 31),
    number_of_simulations=100,
    connection=connection,
    numpy_rng=np.random.default_rng(42)
)

# Run simulation to get carbon prices for different fuels
coal_carbon, gas_carbon, oil_carbon = carbon_sim.run()
```

#### Advanced Example with Price Support

This example demonstrates the carbon price support mechanism:

```python
# Create carbon price simulation
carbon_sim = CarbonPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2025, 12, 31),
    number_of_simulations=1000,
    connection=connection
)

# Run simulation
coal_carbon, gas_carbon, oil_carbon = carbon_sim.run()

# The carbon prices include support mechanisms:
# - Carbon Price Support (e.g., £18/ton)
# - Maximum Total Carbon Price cap

# Plot the simulated carbon prices
carbon_sim.plot_Simulated_Curve(raw_price=True, paths=50)
```

Carbon prices are crucial for energy market modeling as they directly impact the economics of different fuel types.
