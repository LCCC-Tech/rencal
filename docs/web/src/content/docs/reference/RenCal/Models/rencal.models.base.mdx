<Section type="about">
`rencal.models.base` defines abstract and concrete base classes for pandas/xarray-backed dataset models and schema validation.

These Pydantic-backed models are the primary typed data contract returned by [`LocalDataLoader`](/reference/RenCal/Core/rencalcoredata_loader/#localdataloader).
</Section>
