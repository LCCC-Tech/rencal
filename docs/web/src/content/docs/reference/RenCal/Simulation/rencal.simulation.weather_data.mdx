<Section type="about">
`rencal.simulation.weather_data` defines metadata descriptors and the intermittent weather sampler used to create future hourly load-factor streams from historical artifacts.

[`WeatherData`](/reference/RenCal/Simulation/rencalsimulationweather_data/#weatherdata) uses a JSON-parsed [`HistoricalMetadata`](/reference/RenCal/Simulation/rencalsimulationweather_data/#historicalmetadata) descriptor plus a process-scope cache keyed by historical NPY basename to enable safe lazy loading. It supports two sampling modes via `ignore_zeros`:

- **ignore_zeros = False (wind):** all loadfactor values participate in histogram building and resampling.
- **ignore_zeros = True (solar):** zero-valued hours (nighttime) are preserved; histograms and inverse-CDF resampling operate only on non-zero values.

#### Example Usage

```python
import datetime as dt

from rencal.simulation.weather_data import HistoricalMetadata, WeatherData

metadata = HistoricalMetadata(
    npy_basename="historic_wind.npy",
    path_resolver=lambda basename: f"/mnt/data/{basename}",
    data_limit_left=dt.datetime(1980, 1, 1),
    data_limit_right=dt.datetime(2026, 1, 1),
    columns=["wind_lf"],
    hours_per_block=24,
)

weather_data = WeatherData(metadata=metadata, desired_averages={0: [0.38]})
sample = weather_data.random_sample(dt.datetime(2027, 1, 1), dt.datetime(2027, 1, 31))
```
</Section>

- <p><code class="key">columns</code> <code class="primitive">Sequence[str]</code></p>

- <p><code class="key">hours_per_block</code> <code class="primitive">int</code> | <code class="primitive">None</code></p>

### WeatherData

<Segment>
<Section type="signature">
```python
class WeatherData(
    metadata: HistoricalMetadata,
    historical_start_date: DateTimeLike = datetime.datetime(1980, 1, 1),
    historical_end_date: DateTimeLike = datetime.datetime(2026, 1, 1),
    desired_averages: dict[int, list[float]] | None = None,
    prefix_histograms: NDArray[np.uint32] | None = None,
    historical_data: NDArray[np.floating] | None = None,
    ignore_zeros: bool = False,
): WeatherData
```
</Section>

Intermittent weather sampler supporting raw bucketed sampling and optional inverse-CDF resampling against desired averages.

<Section type="parameters">
#### Parameters

- <p><code class="key">metadata</code> [<code class="type">HistoricalMetadata</code>](#HistoricalMetadata)</p>
  Manifest-backed metadata descriptor.

- <p><code class="key">historical_start_date</code> <code class="primitive">DateTimeLike</code></p>
  Earliest historical date considered for sampling.

- <p><code class="key">historical_end_date</code> <code class="primitive">DateTimeLike</code></p>
  Latest historical date considered for sampling.

- <p><code class="key">desired_averages</code> <code class="primitive">dict[int, list[float]]</code></p>
  Target average mapping for transformed columns.

- <p><code class="key">prefix_histograms</code> <code class="primitive">NDArray[np.uint32]</code> | <code class="primitive">None</code></p>
  Optional prefix-histogram artifact for fast histogram queries.

- <p><code class="key">historical_data</code> <code class="primitive">NDArray[np.floating]</code> | <code class="primitive">None</code></p>
  Optional historical data matrix/memmap.

- <p><code class="key">ignore_zeros</code> <code class="primitive">bool</code></p>
  If True, histogram and resampling logic operate on non-zero values only.
</Section>

<InlineSection>
**Returns** [<code class="type">WeatherData</code>](#WeatherData)
</InlineSection>

<InlineSection>
**Raises**
- <code class="type">ValueError</code>: If desired averages are supplied without historical data and prefix histograms.
</InlineSection>
</Segment>
