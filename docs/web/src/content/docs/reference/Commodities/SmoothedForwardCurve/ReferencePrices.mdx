<Section type="about">
This class calculates BMRP (Baseload Market Reference Price) values for power market analysis. BMRP represents the reference price for baseload power contracts and is essential for energy market modeling and forecasting.

#### Simple Example

Here's how to calculate BMRP values:

```python
from quantlib.commodities.SmoothedForwardCurve import ReferencePrices
from quantlib.database.DatabaseDelta import DatabaseDelta
import datetime as dt

# Create database connection
connection = DatabaseDelta()

# Create reference prices calculator
ref_prices = ReferencePrices(
    connection=connection,
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2024, 12, 31)
)

# Calculate BMRP values for each day
bmrp_values = ref_prices.calculate_BMRP()
```

#### Advanced Example with Future Projections

This example shows how to handle future BMRP values:

```python
# For longer-term analysis including future periods
ref_prices = ReferencePrices(
    connection=connection,
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2030, 12, 31)  # Far future analysis
)

# Calculate BMRP values
bmrp_values = ref_prices.calculate_BMRP()

# For periods far in the future, get proxy values
future_bmrp = ref_prices.get_Future_BMRP_Proxy()

# BMRP is used for:
# - Power market reference pricing
# - Baseload contract valuations
# - Energy market forecasting
# - Regulatory price benchmarking

# The values are derived from season-ahead power prices
# on the market date, providing market-based references
```

BMRP values are crucial for power market participants to benchmark baseload electricity prices and assess market conditions.

## Methods

### calculate_BMRP

<Segment>
<Section type="signature">
```ts
calculate_BMRP(): dict
```
</Section>

Calculates BMRP (Baseload Market Reference Price) values for each day in the simulation period. BMRP values are derived from season-ahead power prices on the market date.

<InlineSection>
**Returns** A dictionary of daily BMRP values, taken from season ahead power prices on market date.
</InlineSection>

<InlineSection>
**Return type** <code class="primitive">dict</code>
</InlineSection>
</Segment>

<Segment>
<Section type="signature">
