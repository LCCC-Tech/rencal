<Section type="about">
Reference for historical weather metadata descriptors and weather load-factor sampling.

`WeatherData` supports two resampling modes via `ignore_zeros`:

- `False` (wind): include all values.
- `True` (solar): preserve zeros; optimize/resample on non-zero values only.
</Section>

### WeatherData

<Segment>

```python
class WeatherData(BucketedData)
```

Intermittent weather sampler that stitches historical periods and can apply inverse-CDF resampling for target average control.

#### Constructor

```python
WeatherData(
    metadata: HistoricalMetadata,
    historical_start_date: DateTimeLike = datetime.datetime(1980, 1, 1),
    historical_end_date: DateTimeLike = datetime.datetime(2026, 1, 1),
    desired_averages: dict[int, list[float]] | None = None,
    prefix_histograms: NDArray[np.uint32] | None = None,
    historical_data: NDArray[np.floating] | None = None,
    ignore_zeros: bool = False,
)
```

**Parameters**
- `metadata`: Historical metadata descriptor.
- `historical_start_date`: Earliest date considered for bucketed sampling.
- `historical_end_date`: Latest date considered for bucketed sampling.
- `desired_averages`: Mapping `column_index -> [target_avg_1, target_avg_2, ...]`.
- `prefix_histograms`: Optional precomputed prefix histograms for fast lookups.
- `historical_data`: Optional historical data memmap/array.
- `ignore_zeros`: Enable non-zero-only histogram/resampling mode.

**Raises**
- `ValueError`: If desired averages are requested but neither historical data nor prefix histograms are provided.

##### random_sample

```python
random_sample(

```

Generates future hourly samples by selecting historical draw periods and optionally appending inverse-CDF transformed stream variants.

**Parameters**

- `future_end_date`: Inclusive end date.
- `python_rng`: RNG for date-period bucketing/sampling.
- `numpy_rng`: RNG for inverse-CDF jittering/resampling.

**Returns**
