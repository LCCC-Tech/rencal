<Section type="about">
`rencal.core.data_loader` defines dataset loading interfaces and local implementations for plant, generation, ERA5, and calibrated weather artifacts.

#### Example

```python
from rencal.core.data_loader import LocalDataLoader

loader = LocalDataLoader()
plant = loader.load_plant_data()
generation = loader.load_generation_data()
era5 = loader.load_era5_data()
```
</Section>
