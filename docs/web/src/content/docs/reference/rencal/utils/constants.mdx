<Section type="about">
Reference for package constants loaded from `config.yml` (with runtime/default fallbacks) and used across data download, loading, calibration, and simulation modules.
</Section>

## Module Behavior

<Segment>
On import, this module:

1. Loads `.env` values via `dotenv.load_dotenv()`.
2. Loads YAML config from `rencal/utils/config.yml` when present.
3. Exposes typed constants with config/default fallback logic.
</Segment>
