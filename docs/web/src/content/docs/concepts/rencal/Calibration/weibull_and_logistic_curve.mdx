# Wind Calibration Components

Wind calibration uses two complementary model components:

- [Logistic Power Curve](./logistic_power_curve/) — maps wind speed to expected load factor.
- [Weibull Wind-Speed Distribution](./weibull_wind_speed_distribution/) — models how frequently different wind speeds occur at a location.

Together they support both:

- hourly stream generation from wind speeds (`Wind Streams.parquet`), and
- long-term expected load factor estimation (`Calibration Summary.csv`).
