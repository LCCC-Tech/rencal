## Classes

### VersionedColumnsNDArray

<Segment>

```python
class VersionedColumnsNDArray(n_raw_features: int)
```

Wrapper for sampled output matrix that tracks canonical and transformed column versions.

##### update_mapping

```python
update_mapping(canonical_col: int, j: int) -> int
```

Registers transformed-column absolute index for canonical stream.

**Parameters**
- `canonical_col (int)`
- `j (int)`: 0-based transformed-column creation index.

**Returns**
- `int`: Absolute output-column index.

##### attach_data

```python
attach_data(data: NDArray[np.floating]) -> VersionedColumnsNDArray
```

Attaches final output matrix to the wrapper exactly once.

**Parameters**
- `data (NDArray[np.floating])`: 2D output matrix.

**Returns**
- `VersionedColumnsNDArray`

**Raises**
- `RuntimeError`: If data already attached.
- `ValueError`: If matrix shape is incompatible.

##### access_col

```python
access_col(canonical_col: int, version: int = 0) -> NDArray[np.floating]
```

Returns view of canonical (`version=0`) or transformed (`version>=1`) stream.

**Parameters**
- `canonical_col (int)`
- `version (int)`

**Returns**
- `NDArray[np.floating]`

**Raises**
- `RuntimeError`: If data not attached.
- `IndexError`: If requested version does not exist.
