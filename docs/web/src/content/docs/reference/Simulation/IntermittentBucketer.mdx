<Section type="about">
`rencal.simulation.intermittent_bucketer` provides the default bucketer used by intermittent weather simulations.

`IntermittentBucketer` extends `Bucketer` with a single category (no extra categorical filtering), while preserving month-based bucket seasonality for random historical draw selection.

#### Example

```python
import datetime as dt

from rencal.simulation.intermittent_bucketer import IntermittentBucketer

bucketer = IntermittentBucketer(
    historical_start_date=dt.datetime(1990, 1, 1),
    historical_end_date=dt.datetime(2025, 12, 31),
)
```

### IntermittentBucketer

<Section type="parameters">
#### Parameters

- <p><code class="key">historical_start_date</code> <code class="primitive">datetime.datetime</code></p>
  First historical day available for sampling.

- <p><code class="key">historical_end_date</code> <code class="primitive">datetime.datetime</code></p>
  Last historical day available for sampling.

- <p><code class="key">draw_period</code> <code class="primitive">int</code></p>
  Number of consecutive days represented by one draw.

- <p><code class="key">bucket_definition</code> <code class="primitive">list[ShortDate]</code></p>
  Bucket boundaries used for seasonality-aware sampling.
