<Section type="about">
`rencal.core.data_loader` defines the loader interface and local filesystem implementation used to read plant, generation, and ERA5 weather datasets into typed dataset models.

#### Example

```python
from rencal.core.data_loader import LocalDataLoader

loader = LocalDataLoader()
plant = loader.load_plant_data()
generation = loader.load_generation_data()
era5 = loader.load_era5_data()
```
</Section>

### LocalDataLoader.load_era5_data

<Segment>
<Section type="signature">
```python
load_era5_data() -> ERA5DatasetModel
```
</Section>

Loads ERA5 NetCDF files from the configured local ERA5 directory, combines them on the time dimension, and filters to standard wind/solar variables.

<InlineSection>
**Returns** [<code class="type">ERA5DatasetModel</code>](#ERA5DatasetModel)
</InlineSection>

<InlineSection>
**Raises**
- <code class="type">FileNotFoundError</code>: If no ERA5 NetCDF files are found.
- <code class="type">ValueError</code>: If no files can be loaded successfully, no valid time dimension is present, concatenation fails, or no standard ERA5 variables are available.
</InlineSection>
