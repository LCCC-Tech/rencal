# Calibrator

Abstract base class for the calibration of intermittent generator power curves.

## `class Calibrator(data_path?: string, plant_id_col?: string)`

### `__init__(data_path?: string, plant_id_col?: string)`

Initialises a calibrator instance.

The Calibrator is an abstract class that specifies the methods any intermittent generator’s
calibration should include, as well as setting up and loading input datasets from the
configuration file or user-specified paths.

**Parameters:**

- **data_path** *(string)* — Path to the directory containing the input data files.  
- **plant_id_col** *(string)* — Name of the ID column designating a power plant in the input.

---

### `abstract calculate_historical_load_factors(): void`

Calculates historical load factors.

### `abstract calibrate(): void`

Triggers calibration workflow.

### `abstract estimate_load_factors_for_resource(): void`

Estimates load factors based on historical distribution and full resource availability.

### `abstract extract_resource_timeseries_for_plants(): void`

Extracts resource time series for plants.

### `abstract fit_historical_load_factor_distribution(): void`

Fits a distribution to historical load factors.

### `abstract generate_resource_streams(): void`

Generates load factor streams for available resource time series for each generator.

### `abstract output_estimated_load_factors_tabular(): void`

Outputs a table of estimated load factors.

### `abstract output_estimated_load_factors_visual(): void`

Outputs a series of plots of estimated load factors and calibrated curves.

### `abstract output_historical_load_factor_distribution_parameters(): void`

Writes historical load factor parameters to a CSV file.

### `abstract output_resource_per_plant(): void`

Writes resource time series for each plant to a CSV file.

### `abstract output_resource_streams(): void`

Writes resource streams to a parquet file.
