<Section type="about">
This class handles deterministic commodity prices that don't require stochastic simulation. It's used for commodities like biomass and oil where prices are based on historical data or fixed forward curves rather than Monte Carlo simulation.

#### Simple Example

Here's how to work with non-stochastic commodity prices:

```python
from quantlib.commodities.CommodityPriceSimulation import BiomassPrice
from quantlib.database.DatabaseDelta import DatabaseDelta
import datetime as dt

# Create database connection
connection = DatabaseDelta()

# Create biomass price instance
biomass = BiomassPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2024, 12, 31),
    connection=connection
)

# Get daily fuel prices
daily_prices = biomass.run()
```

#### Advanced Example with Price Interpolation

This example shows how the class handles sparse price data:

```python
# The NonStochasticCommodityPrice class automatically:
# 1. Retrieves historical prices from the database
# 2. Forward-fills missing dates
# 3. Interpolates between price points
# 4. Extends the most recent price to future dates

# Create oil price instance
from quantlib.commodities.CommodityPriceSimulation import OilPrice

oil = OilPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2025, 12, 31),
    connection=connection
)

# Get deterministic daily prices
daily_prices = oil.run()

# The class handles:
# - Sparse price updates (e.g., monthly or quarterly)
# - Historical data gaps
# - Future price extrapolation
# - Unit conversions and transport costs
```

Non-stochastic prices are useful for commodities with regulated prices, long-term contracts, or limited market liquidity.
