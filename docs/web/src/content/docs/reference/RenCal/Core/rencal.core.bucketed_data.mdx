<Section type="about">
`rencal.core.bucketed_data` contains shared histogram and distribution utilities used by bucketer-driven simulators.

The module exposes:

- [`BucketedData`](/reference/RenCal/Core/rencalcorebucketed_data/#bucketeddata): utility base class with histogram and distribution optimization helpers.
- [`VersionedColumnsNDArray`](/reference/RenCal/Core/rencalcorebucketed_data/#versionedcolumnsndarray): array wrapper that tracks canonical columns and transformed variants produced during resampling.

#### Example

```python
# Returned from WeatherData.random_sample(...)
sample = weather_data.random_sample(start, end)

# Access canonical column
base_stream = sample.access_col(1)

# Access first transformed variant of canonical column 1
variant_stream = sample.access_col(1, 1)
```
</Section>
