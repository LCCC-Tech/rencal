## Class

### Bucketer

<Segment>

```python
class Bucketer(
    historical_start_date: datetime.datetime,
    historical_end_date: datetime.datetime,
    categories: int,
    draw_period: int,
    bucket_definition: list[ShortDate],
)
```

Builds hierarchical lookup structures (`bucket_structure`, `lookup_structure`) used to sample historical draw-period start dates conditioned on bucket and category.

#### Constructor Parameters
- `historical_start_date (datetime.datetime)`: Midnight start of earliest historical day.
- `historical_end_date (datetime.datetime)`: Midnight start of latest historical day.
- `categories (int)`: Number of category partitions.
- `draw_period (int)`: Consecutive days represented by one draw.
- `bucket_definition (list[ShortDate])`: Strictly increasing bucket boundaries.

#### Constructor Raises
- `ValueError`: If historical dates are not ordered.
- `TypeError`: If `bucket_definition` is not a list.
- `ValueError`: If bucket definition has fewer than 2 entries.
- `ValueError`: If bucket definition is not strictly ordered.
- `ValueError`: If any bucket interval is smaller than `draw_period`.
