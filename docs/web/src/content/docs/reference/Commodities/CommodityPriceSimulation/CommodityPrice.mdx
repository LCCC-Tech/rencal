<Section type="about">
This abstract base class provides the foundation for simulating commodity prices by applying stochastic processes to their respective forward curves. It initializes commodities such as carbon, coal, or gas, retrieves smoothed forward price curves, and sets up stochastic parameters from the database.

#### Implementation Overview

The CommodityPrice class serves as a base for specific commodity price simulations. It handles:
- Forward curve retrieval and smoothing
- Stochastic parameter initialization
- Geometric Brownian Motion process setup
- Price simulation plotting capabilities

#### Example Usage

While you cannot instantiate this abstract class directly, here's how it's used through its subclasses:

```python
from quantlib.commodities.CommodityPriceSimulation import CoalPrice
from quantlib.database.DatabaseDelta import DatabaseDelta
import datetime as dt

# Create a database connection
connection = DatabaseDelta()

# Create a coal price simulation
coal_sim = CoalPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2024, 12, 31),
    number_of_simulations=1000,
    connection=connection
)

# Run the simulation
daily_prices = coal_sim.run()

# Plot the results
coal_sim.plot_Simulated_Curve(paths=50)
```

All commodity-specific classes inherit from this base class and implement their own `run()` and `daily_Fuel_Price()` methods.

<Section type="parameters">
#### Parameters

- <p><code class="key">raw_price</code> <code class="primitive">bool</code></p>
