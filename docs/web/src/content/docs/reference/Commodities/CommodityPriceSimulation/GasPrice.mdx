<Section type="about">
This class simulates gas prices using a combination of Geometric Brownian Motion and Normal Inverse Gaussian Lévy processes. The NIG process captures the heavy tails and skewness often observed in gas price distributions.

#### Simple Example

Here's a basic example of simulating gas prices:

```python
from quantlib.commodities.CommodityPriceSimulation import GasPrice
from quantlib.database.DatabaseDelta import DatabaseDelta
import datetime as dt
import numpy as np

# Create database connection
connection = DatabaseDelta()

# Create gas price simulation
gas_sim = GasPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2024, 12, 31),
    number_of_simulations=100,
    connection=connection,
    numpy_rng=np.random.default_rng(42)
)

# Run simulation to get daily fuel prices
daily_prices = gas_sim.run()
```

#### Advanced Example with Monthly Aggregation

This example demonstrates monthly price aggregation:

```python
# Create gas price simulation
gas_sim = GasPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2025, 12, 31),
    number_of_simulations=1000,
    connection=connection
)

# Run simulation for daily prices
daily_prices = gas_sim.run()

# Get monthly average prices
monthly_prices = gas_sim.monthly_Fuel_Price(gas_sim.Pt)

# The gas price simulation includes:
# - Winter/Summer seasonality parameters
# - Heavy-tailed distributions via NIG process
# - Conversion from pence/therm to £/MWh

# Plot the simulated prices
gas_sim.plot_Simulated_Curve(raw_price=False, paths=50)
```

Gas prices exhibit complex dynamics including seasonality, jumps, and heavy tails, all captured by the NIG-GBM combination.
