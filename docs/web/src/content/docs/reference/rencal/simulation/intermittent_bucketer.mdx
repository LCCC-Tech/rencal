<Section type="about">
Reference for the default intermittent bucketer used by weather simulation.

It inherits `Bucketer` and uses a single category with monthly bucket definitions by default.
</Section>

## Class

### IntermittentBucketer

<Segment>

```python
class IntermittentBucketer(
    historical_start_date,
    historical_end_date,
    draw_period=7,
    bucket_definition=MONTHLY_BUCKET_DEFINITION,
)
```

#### Constructor Parameters
- `historical_start_date`: Earliest historical date.
- `historical_end_date`: Latest historical date.
- `draw_period (int)`: Days per draw (default `7`).
- `bucket_definition`: `ShortDate` bucket boundaries (default monthly partition).

#### Methods

##### assign_category

```python
assign_category(date) -> int
```
