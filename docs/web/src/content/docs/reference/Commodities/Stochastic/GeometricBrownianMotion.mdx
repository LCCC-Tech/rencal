## Constructor

<Segment>
<Section type="signature">
```python
class GeometricBrownianMotion(mu: float, sigma: float, n: int,
paths: int, numpy_rng: ~numpy.random._generator.Generator, p0: int = 1): GeometricBrownianMotion
```
</Section>

<Section type="parameters">
#### Parameters

- <p><code class="key">mu</code> <code class="primitive">float</code></p>
  Drift coefficient.

- <p><code class="key">sigma</code> <code class="primitive">float</code></p>
  Volatility coefficient.

- <p><code class="key">n</code> <code class="primitive">int</code></p>
  Number of time steps (e.g., n = 365 days).

- <p><code class="key">paths</code> <code class="primitive">int</code></p>
  Number of paths - default = 1.

- <p><code class="key">p0</code> <code class="primitive">int</code></p>
  Initial y value - default = 1.
</Section>

<InlineSection>
