<Section type="about">
The data downloader module provides a common base class plus concrete implementations for acquiring weather and energy data used by the forecasting pipeline. It includes downloaders for ERA5 reanalysis data (Copernicus CDS), CfD register and BMU mappings (LCCC), and Elexon BMRS generation data, plus a manager that orchestrates the full workflow.

#### Implementation Overview

The data downloaders handle:
- Directory setup for persisted data downloads
- ERA5 retrieval and metadata verification
- CfD register and BMU mapping enrichment
- Generation data aggregation to hourly UTC
- A unified `DownloadManager` API for running all steps

#### Prerequisites

- **Copernicus CDS account and API key** for ERA5 downloads
- Network access to CDS, LCCC, and Elexon endpoints
- Python dependencies: `cdsapi`, `xarray`, `pandas`, `requests`, `numpy`, `tqdm`, `certifi`
- Sufficient disk space for multi-year ERA5 NetCDF files

#### CDS API Key Usage

ERA5 downloads require a CDS API key. You can provide it in either of the following ways:

- **Environment variable**: Set `CDS_API_KEY` in your environment, and optionally `CDS_API_URL` to override the default.
- **Constructor argument**: Pass `api_key` (and optionally `api_url`) directly to `ERA5DataDownloader` or `DownloadManager`.

If no key is provided, ERA5 downloads will raise an error when the client is initialized.

#### Example Usage

Using environment variables:

```python
import os
from weather.core.data_downloader import DownloadManager

os.environ["CDS_API_KEY"] = "uid:token"

downloader = DownloadManager()
downloader.download_era5()
```

Passing the key explicitly:

```python
from weather.core.data_downloader import ERA5DataDownloader

era5 = ERA5DataDownloader(api_key="uid:token")
era5.download()
```

The default output directory is `data/` (via `DOWNLOAD_DATA_DIR`) and data is written to subfolders such as `era5/`, `plant/`, and `generation/`.

## Methods

### ERA5DataDownloader.download

<Segment>
<Section type="signature">
```python
download() -> None
```
</Section>

Downloads ERA5 reanalysis data for all calibration years. Each year is retrieved in two requests (wind and solar), merged into a single NetCDF file, and validated for time metadata. Existing files are verified and reused when possible.

<InlineSection>
**Returns** None
</InlineSection>
</Segment>

### CfDDataDownloader.download

<Segment>
<Section type="signature">
```python
download() -> None
```
</Section>

Downloads the CfD register from the LCCC API and the BMU mapping CSV, merges them by CfD ID, and writes the resulting dataset to CSV.

<InlineSection>
**Returns** None
</InlineSection>
</Segment>

### GenerationDataDownloader.download

<Segment>
<Section type="signature">
```python
download() -> None
```
</Section>

Loads the CfD/BMU mapping, retrieves settled generation data from Elexon for all associated BMUs, aggregates to hourly UTC by CfD ID, and writes the data to Parquet.

<InlineSection>
**Returns** None
</InlineSection>
