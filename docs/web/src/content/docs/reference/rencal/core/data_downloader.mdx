### ERA5DataDownloader

<Segment>

```python
class ERA5DataDownloader(api_key: str | None = None, api_url: str | None = None)
```

Downloader for ERA5 weather reanalysis data from the Copernicus CDS API.

#### Constructor Parameters
- `api_key (str | None)`: CDS API key (fallback: `CDS_API_KEY` env var).
- `api_url (str | None)`: CDS API URL override (fallback: env/config default).

#### Properties

##### client

```python
client -> cdsapi.Client
```

Lazily initializes authenticated CDS client with SSL verification.

**Raises**
- `ValueError`: If API key is missing.

#### Methods

##### download

```python
download() -> None
```

Downloads or verifies yearly ERA5 files over calibration period, then verifies metadata.

##### _extract_calibration_years

```python
_extract_calibration_years() -> list[int]
```

Parses calibration date range and returns inclusive list of years.

**Returns**
- `list[int]`

##### _download_year

```python
_download_year(year: int, file_path: str) -> None
```

Downloads wind and solar requests for a single year, merges outputs, removes temporary files.

**Parameters**
- `year (int)`
- `file_path (str)`

##### _verify_and_update_metadata

```python
_verify_and_update_metadata(year: int, file_path: str) -> None
```

Verifies datetime coordinate presence and rewrites file metadata annotations.

##### _find_datetime_coordinate

```python
_find_datetime_coordinate(ds: xr.Dataset) -> str | None
```

Finds likely datetime coordinate by coordinate name patterns.

### GenerationDataDownloader

<Segment>

```python
class GenerationDataDownloader()
```

Downloader for settled generation data from Elexon BMRS and hourly UTC aggregation logic.

#### Methods

##### download

```python
download() -> None
```

Loads CfD/BMU mapping, downloads generation, aggregates by CfD and hour, writes parquet.

##### _get_cfd_plants

```python
_get_cfd_plants() -> pd.DataFrame
```

Loads local CfD/BMU mapping and records unique BMU IDs for request construction.

##### _download_generation_data

```python
_download_generation_data() -> pd.DataFrame
```

Requests settled generation data from Elexon API over calibration period.

##### _get_day_type_from_period_counts

```python
_get_day_type_from_period_counts(generation_df: pd.DataFrame) -> pd.Series
```

Classifies dates as normal/short/long settlement days using period counts.

##### _create_hourly_utc_datetime

```python
_create_hourly_utc_datetime(generation_df: pd.DataFrame) -> pd.Series
```

Converts settlement-date/period rows to hourly UTC timestamps accounting for DST patterns.

##### _divide_shared_bmu_generation (static)

```python
_divide_shared_bmu_generation(generation_df: pd.DataFrame) -> pd.DataFrame
```

Splits shared-BMU generation proportionally by plant capacity.

##### _aggregate_bmu_generation_to_cfd

```python
_aggregate_bmu_generation_to_cfd(
    cfd_df: pd.DataFrame,
    generation_df: pd.DataFrame,
) -> pd.DataFrame
```

Merges BMU generation with CfD mapping and performs final hourly aggregation.
