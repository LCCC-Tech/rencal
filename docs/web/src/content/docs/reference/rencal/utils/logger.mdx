## Functions

### get_logger

<Segment>

```python
get_logger(name: str | None = None, level: int = logging.DEBUG) -> logging.Logger
```

Returns a configured logger with project-standard formatting.

#### Parameters

- `name (str | None)`: Logger name (defaults to caller module name).
- `level (int)`: Fallback logging level (mode flags may override).

#### Returns

- `logging.Logger`

#### Behavior

- Uses caller module name when `name` is omitted.
- Avoids duplicate handlers when logger already exists.
- Applies level overrides based on `QUIET_MODE` / `VERBOSE_MODE` flags from constants.
- Configures console formatter: `[LEVEL] - message - [module] - timestamp`.
