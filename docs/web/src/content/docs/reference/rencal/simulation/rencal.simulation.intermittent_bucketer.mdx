<Section type="about">
`rencal.simulation.intermittent_bucketer` provides the default single-category bucketer for intermittency sampling.

[`IntermittentBucketer`](/reference/rencal/simulation/rencalsimulationintermittent_bucketer/#intermittentbucketer) extends [`Bucketer`](/reference/rencal/core/rencalcorebucketer/#bucketer) with a single category (no extra categorical filtering), while preserving month-based bucket seasonality for random historical draw selection.

#### Example

```python
import datetime as dt

from rencal.simulation.intermittent_bucketer import IntermittentBucketer

bucketer = IntermittentBucketer(
    historical_start_date=dt.datetime(1990, 1, 1),
    historical_end_date=dt.datetime(2025, 12, 31),
)
```
</Section>

- <p><code class="key">historical_end_date</code> <code class="primitive">datetime.datetime</code></p>

- <p><code class="key">draw_period</code> <code class="primitive">int</code></p>

- <p><code class="key">bucket_definition</code> <code class="primitive">list[ShortDate]</code></p>
