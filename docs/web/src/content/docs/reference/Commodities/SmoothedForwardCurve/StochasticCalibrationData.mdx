<Section type="about">
This class extracts historical market data for calibrating stochastic process parameters. It provides day-ahead and month-ahead price series for gas, coal, and carbon that are used to estimate volatility, mean reversion, and other stochastic parameters.

#### Simple Example

Here's how to extract calibration data:

```python
from quantlib.commodities.SmoothedForwardCurve import StochasticCalibrationData
from quantlib.database.DatabaseDelta import DatabaseDelta
import datetime as dt

# Create database connection
connection = DatabaseDelta()

# Create calibration data extractor
calibration = StochasticCalibrationData(
    start_date=dt.datetime(2020, 1, 1),
    end_date=dt.datetime(2023, 12, 31),
    connection=connection
)

# Extract gas day-ahead prices (winter and summer)
winter_gas, summer_gas = calibration.gas_Day_Ahead()

# Extract coal month-ahead prices
coal_prices = calibration.coal_Month_Ahead()

# Extract carbon year-ahead prices
carbon_prices = calibration.carbon_Year_Ahead(forward_fill=True)
```

#### Advanced Example with Parameter Estimation

This example shows how the data is used for stochastic calibration:

```python
from quantlib.commodities.Stochastic import max_Likelihood_Estimation
import numpy as np

# Extract longer historical period for robust calibration
calibration = StochasticCalibrationData(
    start_date=dt.datetime(2015, 1, 1),
    end_date=dt.datetime(2023, 12, 31),
    connection=connection
)

# Get gas data for different seasons
winter_gas, summer_gas = calibration.gas_Day_Ahead()

# Get coal data
coal_data = calibration.coal_Month_Ahead()

# Calculate log returns for stochastic parameter estimation
gas_returns = np.diff(np.log(winter_gas[winter_gas > 0]))
coal_returns = np.diff(np.log(coal_data[coal_data > 0]))

# Use for Ornstein-Uhlenbeck calibration (coal)
if len(coal_returns) > 10:
    ou_sigma, ou_kappa = max_Likelihood_Estimation(coal_returns)

# The calibration data is essential for:
# - Estimating volatility parameters
# - Calculating mean reversion speeds
# - Determining seasonal patterns
# - Calibrating NIG distribution parameters

# Different contract types capture different market dynamics:
# - Day-ahead: Short-term volatility and jumps
# - Month-ahead: Medium-term mean reversion
# - Year-ahead: Long-term trend parameters
```

This data forms the foundation for all stochastic parameter estimation in the QuantLib framework.
