<Section type="about">
`rencal.core.short_date` defines year-agnostic month/day values used by bucket definitions.

[`ShortDate`](/reference/rencal/core/rencalcoreshort_date/#shortdate) stores month/day pairs, validates them against non-leap-year semantics for deterministic partitioning, and implements rich comparison operators so it can be ordered and searched efficiently inside bucket definitions.

#### Example

```python
import datetime as dt

from rencal.core.short_date import ShortDate

start = ShortDate.from_list([1, 1])
end = ShortDate(dt.datetime(2024, 3, 1))

assert start < end
```
</Section>
