## `static logistic_function(x, b, c, g): number | ndarray`

Defines a generalised logistic function in the log domain for stability and calculates its value for any numeric input `x`.

The generalised logistic function has five parameters defining its shape; this implementation forces the minimum and maximum values to **0** and **1**, respectively, since load factors must lie within that range.

The non‑log‑domain logistic function is:

$$
f(x) = d \;+\; \frac{a - d}{\left( 1 + \left( \frac{x}{c} \right)^b \right)^g}
$$

- *a* — minimum bound  
- *b* — steepness  
- *c* — inflection point location  
- *d* — maximum bound  
- *g* — asymmetry  

**Parameters:**

- **x** *(number | ndarray)* — wind speed  
- **b** *(number)* — steepness parameter  
- **c** *(number)* — inflection point location  
- **g** *(number)* — asymmetry parameter  

**Returns:**  
Outputs of the generalised logistic function for each `x` value with the specified parameters.

**Return type:** `number | ndarray`

## `static weibull_function(x, k_val, lambda_val): number | ndarray`

Calculates the value of a Weibull distribution for any numeric input `x`.

The equation of the Weibull distribution is:

$$
f(x) = \frac{k}{\lambda} \left( \frac{x}{\lambda} \right)^{k - 1} \exp\!\left( -\left( \frac{x}{\lambda} \right)^k \right)
$$

- *k* — shape parameter  
- *λ* — scale parameter  
- *e* — Euler’s number  

**Parameters:**

- **x** *(number | ndarray)* — wind speed inputs  
- **k_val** *(number)* — shape parameter  
- **lambda_val** *(number)* — scale parameter  

**Returns:**  
Value of the Weibull function at each `x`.

**Return type:** `number | ndarray`
