<Section type="about">
This class simulates correlated gas day-ahead and month-ahead prices. It ensures both price series share the same Geometric Brownian Motion process to maintain realistic correlation between spot and forward prices.

#### Simple Example

Here's how to simulate correlated day-ahead and month-ahead gas prices:

```python
from quantlib.commodities.CommodityPriceSimulation import GasMonthAndDayAheadPrice
from quantlib.database.DatabaseDelta import DatabaseDelta
import datetime as dt
import numpy as np

# Create database connection
connection = DatabaseDelta()

# Create correlated gas price simulation
gas_sim = GasMonthAndDayAheadPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2024, 12, 31),
    number_of_simulations=100,
    connection=connection,
    numpy_rng=np.random.default_rng(42)
)

# Run simulation to get both price series
month_ahead, day_ahead = gas_sim.run()
```

#### Advanced Example with Spread Analysis

Analyze the spread between month-ahead and day-ahead prices:

```python
# Create simulation with many paths
gas_sim = GasMonthAndDayAheadPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2025, 12, 31),
    number_of_simulations=1000,
    connection=connection
)

# Run simulation
month_ahead, day_ahead = gas_sim.run()

# Calculate spreads
spread = month_ahead - day_ahead

# Analysis of correlated prices:
# - Both use the same GBM process for correlation
# - Each has independent NIG processes for idiosyncratic risk
# - Month-ahead typically less volatile than day-ahead
# - Spread represents forward premium/discount

# The shared GBM ensures realistic correlation
# while separate volatilities capture term structure
```

This class is essential for modeling gas forward curves and basis risk between different contract maturities.

## Methods

### run

<Segment>
<Section type="signature">
```ts
run(): tuple[ndarray, ndarray]
```
</Section>

Runs one simulation of correlated gas prices. Both day-ahead and month-ahead prices share the same GBM process but use their own volatility parameters and NIG processes.

<InlineSection>
**Returns** A tuple containing:
- np.ndarray: Monthly fuel prices for month-ahead contracts (£/MWh)
- np.ndarray: Monthly fuel prices for day-ahead contracts (£/MWh)
