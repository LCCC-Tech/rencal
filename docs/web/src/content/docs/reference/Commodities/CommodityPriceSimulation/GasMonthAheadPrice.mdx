<Section type="about">
This class simulates gas month-ahead prices, which are forward contracts for gas delivery one month in the future. It uses the same stochastic processes as the GasPrice class but returns monthly averaged prices.

#### Simple Example

Here's a basic example of simulating gas month-ahead prices:

```python
from quantlib.commodities.CommodityPriceSimulation import GasMonthAheadPrice
from quantlib.database.DatabaseDelta import DatabaseDelta
import datetime as dt
import numpy as np

# Create database connection
connection = DatabaseDelta()

# Create gas month-ahead price simulation
gas_ma_sim = GasMonthAheadPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2024, 12, 31),
    number_of_simulations=100,
    connection=connection,
    numpy_rng=np.random.default_rng(42)
)

# Run simulation to get monthly prices
monthly_prices = gas_ma_sim.run()
```

#### Advanced Example with Price Comparison

Compare month-ahead with day-ahead prices:

```python
from quantlib.commodities.CommodityPriceSimulation import GasPrice, GasMonthAheadPrice

# Same parameters for both simulations
params = {
    'start_date': dt.datetime(2024, 1, 1),
    'end_date': dt.datetime(2025, 12, 31),
    'number_of_simulations': 1000,
    'connection': connection,
    'numpy_rng': np.random.default_rng(42)
}

# Create both simulations
gas_da = GasPrice(**params)
gas_ma = GasMonthAheadPrice(**params)

# Run simulations
daily_prices = gas_da.run()
monthly_prices = gas_ma.run()

# Month-ahead prices are typically:
# - Less volatile than day-ahead
# - Better for hedging monthly consumption
# - Used for forward contract pricing
```

Month-ahead prices are essential for gas market participants who need to hedge or plan for future consumption.
