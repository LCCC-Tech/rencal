<Section type="about">
This class handles biomass price simulation using deterministic (non-stochastic) methods. Biomass prices are typically based on long-term contracts or regulatory mechanisms rather than volatile market dynamics.

#### Simple Example

Here's how to simulate biomass prices:

```python
from quantlib.commodities.CommodityPriceSimulation import BiomassPrice
from quantlib.database.DatabaseDelta import DatabaseDelta
import datetime as dt

# Create database connection
connection = DatabaseDelta()

# Create biomass price simulation
biomass = BiomassPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2024, 12, 31),
    connection=connection
)

# Get daily fuel prices
daily_prices = biomass.run()  # Returns prices in £/MWh
```

#### Advanced Example with Long-term Analysis

Biomass is often used for long-term energy planning:

```python
# Create long-term biomass price forecast
biomass = BiomassPrice(
    start_date=dt.datetime(2024, 1, 1),
    end_date=dt.datetime(2040, 12, 31),  # Long-term horizon
    connection=connection
)

# Get prices
daily_prices = biomass.run()

# Biomass characteristics:
# - Renewable energy source
# - Relatively stable pricing due to contracts
# - Transport costs significant due to low energy density
# - Calorific value conversion important for MWh pricing
# - Often supported by government incentives

# Prices include transport costs and calorific value conversion
```

Biomass is an important renewable fuel for power generation and heating, with prices that are generally more stable than fossil fuels.

## Inherited Methods

This class inherits all methods from [NonStochasticCommodityPrice](#NonStochasticCommodityPrice):

- `run()`: Returns daily fuel prices
- `daily_Fuel_Price()`: Converts raw prices to £/MWh
- `generate_Daily_Fuel_Price()`: Processes historical data
- `generate_Variable_Price_List()`: Interpolates price data
