## Functions

### get_logger

<Segment>
<Section type="signature">
```python
get_logger(name: str | None = None, level: int = logging.DEBUG) -> logging.Logger
```
</Section>

Returns configured logger with consistent formatting and mode-based level behavior.

<Section type="parameters">
#### Parameters

- <p><code class="key">name</code> <code class="primitive">str</code> | <code class="primitive">None</code></p>
  Logger name. If omitted, calling module name is inferred.

- <p><code class="key">level</code> <code class="primitive">int</code></p>
  Fallback logger level before QUIET/VERBOSE overrides.
</Section>

<InlineSection>
