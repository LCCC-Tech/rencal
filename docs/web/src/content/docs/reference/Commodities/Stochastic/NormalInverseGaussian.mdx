<Section type="about">
This class implements the Normal Inverse Gaussian Lévy process. It is used to simulate an array of random paths for mean-reverting stochastic processes.

#### Simple Example

Here's a simple example of creating a Normal Inverse Gaussian process:

```python
from quantlib.commodities.Stochastic import NormalInverseGaussian
import numpy as np

# Create a Normal Inverse Gaussian process
nig = NormalInverseGaussian(
    alpha=2.0,
    beta=0.5,
    n=365,
    sigma=0.2,
    theta=0.0,
    kappa=0.5,
    paths=100,
    mu=0.0,
    delta=1.0,
    numpy_rng=np.random.default_rng(42)
)

# Generate paths
paths = nig.run_Path()
```

#### Advanced Example

Here's a more advanced example showing how to use the Normal Inverse Gaussian process for gas price simulation:

```python
from quantlib.commodities.Stochastic import NormalInverseGaussian
import numpy as np

# Parameters for gas price simulation
alpha = 1.5  # Tail heaviness
beta = 0.3   # Skew parameter
n = 252      # Trading days in a year
sigma = 0.3  # Volatility
theta = 0.0  # Long term mean
kappa = 0.8  # Mean reversion
paths = 1000 # Number of simulations

# Create the process
nig = NormalInverseGaussian(
    alpha=alpha,
    beta=beta,
    n=n,
    sigma=sigma,
    theta=theta,
    kappa=kappa,
    paths=paths,
    mu=0.0,
    delta=1.0,
    numpy_rng=np.random.default_rng(42)
)

# Generate paths
paths = nig.run_Path()
```

The Normal Inverse Gaussian distribution is particularly useful for modeling asset returns with heavy tails and skewness, making it ideal for energy commodities like gas.
