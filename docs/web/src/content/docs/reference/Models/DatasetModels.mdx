<Section type="about">
`rencal.models` defines validated dataset containers for plant metadata, generation time series, and ERA5 weather arrays.

These Pydantic-backed models are the primary user-facing data contract returned by `LocalDataLoader`, and provide typed filtering/selectors plus conversion helpers (`to_pandas()`, `to_xarray()`).
</Section>

<Segment>
<Section type="signature">

## Concrete Models

### PlantDatasetModel

<Segment>
<Section type="signature">
```python
class PlantDatasetModel(PandasDatasetModel): PlantDatasetModel
```
</Section>

Validated plant/facility dataset containing location, technology and capacity columns.

<InlineSection>
**Required Columns** <code class="primitive">plant_id</code>, <code class="primitive">latitude</code>, <code class="primitive">longitude</code>, <code class="primitive">technology</code>, <code class="primitive">capacity</code>
</InlineSection>
</Segment>

### GenerationDatasetModel

<Segment>
<Section type="signature">
```python
class GenerationDatasetModel(PandasDatasetModel): GenerationDatasetModel
```
</Section>

Validated hourly generation dataset keyed by `plant_id` and `time`.

<InlineSection>
**Required Columns** <code class="primitive">plant_id</code>, <code class="primitive">time</code>, <code class="primitive">quantity</code>
</InlineSection>
</Segment>

### ERA5DatasetModel

<Segment>
<Section type="signature">
```python
class ERA5DatasetModel(XArrayDatasetModel): ERA5DatasetModel
```
</Section>

Validated ERA5 xarray dataset with required wind components and time dimension checks.

<InlineSection>
**Required Variables** <code class="primitive">u100</code>, <code class="primitive">v100</code>
</InlineSection>
</Segment>
